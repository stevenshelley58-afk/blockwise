# Ad Radar canonical rebuild — 2026-09-07

## Shipped architecture

Ad Radar has one data path: the existing research PostgreSQL database, the
`blockwise-ad-collector` queue job, deterministic parse/upsert, verified local
media archive, Hermes' authenticated API, and the existing Blockwise and Frank
interfaces. Search is read-only and never starts collection. Collection does
not queue AI.

The customer token can read only ad search, ad detail, and verified media.
Prospects, run evidence, collection controls, provider costs, and contact data
remain operator-only. Source media URLs are provenance and never a playback
fallback.

The narrow worker accepts only new `ad-radar:` collector jobs and their marked
media children. An exact-job mode executes one eligible queue row. Claims are
idempotent, respect retry availability and attempt limits, and carry the
per-page credit ceiling through provider reservation and settlement.
