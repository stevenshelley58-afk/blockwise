Historical release evidence, not a permanent current-version claim.

## Scope and revision
Compiled application `2401cbfcfb56f7dadd64af70bb49eecb93fa6567`, immutable image `blockwise-app:2401cbfcfb56f7dadd64af70bb49eecb93fa6567`. Source `/projects/blockwise-ux-swarm-20260908`, branch `feat/mobile-home-pilot-20260908`.

Home no longer repeats workspace identity, initials, setup progress/milestones, reporting, tool-directory or workspace administration sections. It has one title, plain account control, consistent House/Megaphone/ChartNoAxesCombined/UsersRound/Ellipsis navigation, and bounded content-width actions. Other routes preserve their existing treatment.

Recommendations reuse the active, schema-validated customer template catalog and authenticated preview/detail routes. Workspace-scoped direct-ad and legacy-campaign records determine prior use. First-ad users get lower-input-count starter suggestions; returning users get newest-imported unused templates. Drafts count as having tried a template. Missing mappings do not turn an existing customer into a first-time user. Catalog/read failures, empty, exhausted and failed-preview states stay truthful. No provider calls, template activation or database migration was introduced.

Therefore production currently shows the honest empty-catalog state, not a real creative recommendation. Completing the intended creative experience requires a separate reviewed-template publishing decision.

Fixture tests prove state/layout/target wiring, not a live template's quality or full creation flow.
