The one thing to understand

The Ad Studio is a beautifully built front-end shell wired to almost nothing. Of the ~36 api/adstudio/* endpoints that already work, the UI calls only three (Generate, Save, Export). Updating the brand pack, picking a library image, the six Copy "assist" chips, Duplicate / Approve / Archive / Delete, Regenerate, the real publish-readiness check — all are dead <button>s or hard-coded values. The backend for most already exists, so the bulk of the work is wiring, not building. The design is good; it needs to be connected and sequenced.

What's working well (keep it)

  • The four-zone layout — nav rail → setup → live preview → inspector — is the right structure.
  • The live ad preview (Story/Feed/Creative with selectable headline/body/CTA) is polished and the best part of the product.
  • Generate variants works end-to-end (POST /campaigns → 201), as do Save and Export creatives.
  • The readiness checklist is the right concept — it just needs to be real.
  • A responsive mobile layout already exists.

Phase 0 — Stop breaking trust

~½ day · low risk
  1. C3Disable the Vercel Toolbar on production (config) — removes the HUD, INP pop-ups and console crash.
  2. C2Add outside-click + Escape dismissal to the "…" menu (~10 lines).
  3. H3·H4Compute readiness from real state (can now reach 100%).
  4. H5Red over-limit counter + warning when copy exceeds Meta limits.
  5. C4Badge demo data as "Sample campaign" until the real empty state ships.

Phase 1 — Make the visible buttons real

~1–2 days
  1. C1Brand pack: editable fields + Re-scan / Save / Approve (APIs exist). Highest user value.
  2. H1·H2Wire the Copy assist chips and implement all six behaviours.
  3. H6Make media-library tiles selectable; optional "Generate image".
  4. H9Wire "…" + variant actions to existing endpoints (duplicate, regenerate, archive).
  5. H7Make "Preview" open a real full-size preview (or remove it).

Phase 2 — Fix the flow & information architecture

~1–2 days
  1. M1Split Export (manual) from Publish (live) and surface the real publish-readiness checklist.
  2. M2Collapse duplicate entry points — one trigger per action.
  3. M3·M4Keep the user in place on Generate; make the Campaign goal actually drive it.
  4. M5Sync variant labels and preview to one source of truth.
  5. M6·M7Ordered steps + live ticks on the rail; real empty/loading states.
