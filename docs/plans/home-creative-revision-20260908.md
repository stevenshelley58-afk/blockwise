# Home creative revision, 8 September 2026

Current user direction supersedes the earlier Home pilot layout.

Home should answer what to create next, not repeat account identity, setup tracking, reporting or destinations already one tap away. New users see a real template to make their first ad. Returning users see eligible creative templates they have not used. Suggestions must come from the existing approved customer catalog and respect workspace scope. No invented popularity, freshness dates or guaranteed outcomes.

Visual direction: a compact native creative workspace. One Home bar, no initials, no workspace-name strip, no theme toggle. One real creative preview leads the screen, with its name, a compact Use template action and a next-suggestion control. A restrained Browse templates link remains available. Never a screen-wide button, on any viewport. No setup checklist, generic metrics, tool directory, billing panel or repeated login context on Home.

Existing palette and fonts remain. Use one consistent outline icon vocabulary and 44px touch targets. Continuous white surface, no card-panel stack, no decoration standing in for real ads. Preserve safe creation gates and truthful unavailable states. Empty catalog should offer browsing without fabricating preview artwork. If no unused template exists, do not label a used one as new.

Scope: Home and its route-scoped navigation treatment. Other screens remain unchanged. Current customer UI is light-only. Final acceptance must cover new, returning, exhausted/empty and failed catalog cases, real preview loading, actual template selection, mobile and desktop, and no full-width CTA.
